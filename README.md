# কল ব্রিজ — Call Bridge

Bangladesh Call Bridge with friends — fair, light, no casino, in Bangla.

Play in your browser: https://monemchowdhury.github.io/call-bridge/

- You against 3 bots (Rafi, Nusrat, Tanvir), Bangladesh rules
- Bangla and English interface
- Fair shuffle: every deal comes from the code shown at the top
- Balanced deals, 30-second turn timer, sound with mute
- Friend rooms: open a room, share the link, friends join from their phones (peer-to-peer)

## Credits

Card faces: Byron Knoll's vector playing cards, released into the public domain
(https://github.com/notpeter/Vector-Playing-Cards).
All sounds are generated in code; no audio files are used.
Online play uses PeerJS 1.5.5 (MIT licence, vendor/peerjs.min.js). The free PeerJS broker only introduces
the phones to each other; names and moves go directly between phones and are never stored on a server.
